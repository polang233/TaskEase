# 轻程宣传视频

28 秒短视频节奏版，1920×1080，30fps，120 BPM，场景切换都落在拍点上。用 [Remotion](https://www.remotion.dev) 编写，配乐由 `music.py` 用标准库合成。软件名一律用泛称（远程桌面、聊天软件、浏览器、网盘同步）。

```sh
npm install
python3 music.py 28   # 生成配乐 public/music.wav
npm run studio   # 浏览器里预览、逐帧调整
npm run render   # 输出 out/TaskEase-promo.mp4
```

## 分镜

| 时间 | 场景 | 文案 |
| --- | --- | --- |
| 0–2s | 温度猛升到 83°C，画面抖动 | 后台只挂了个远程桌面…… / MacBook Air 直接烫手 |
| 2–5s | 活动监视器，WindowServer 高亮放大 | 每个应用都很“清白” / GPU 71%，全记在系统进程名下 |
| 5–7.5s | 帧率 144 → 10 | 打游戏时，切到后台会自动降帧 / 那别的应用，为什么不行？ |
| 7.5–9s | Logo 闪白落地 | 轻程 TaskEase · 你没在看的应用，就让它歇着 |
| 9–18s | 三步用法：选应用 → 打开限制选“暂停” → 切走 3·2·1 暂停、GPU 归零降温 → 切回秒恢复 | ①②③ |
| 18–24s | 六宫格能力连击（网络限速标“开发中”） | 不止能暂停 |
| 24–28s | 结尾 | 切走即静，切回如初。 |

温度、GPU 数值为示意，正式发布前建议换成实测数据。
