# TaskEase 图标叠层概念

[A / B 对比图](TaskEase-icon-comparison.png)使用内置 imagegen 生成，作为视觉选择预览。当前应用仍使用 Resources/AppIcon.icon 的双叶图标。

- A：青绿与浅绿的叠层叶片，延续轻量感，并用错位、遮挡和材质表达前后台层次。
- B：蓝色后层与浅色前层的任务卡片，突出前后台任务和切换的几何关系。

选定方向后再制作独立透明图层，由 Icon Composer 配置背景、材质、光照和各外观。对比图中的材质是概念效果，正式图标以系统渲染为准。

## 生成提示词

Use case: logo-brand. Asset type: a single wide comparison board for two NEW macOS app icon concepts for TaskEase, a utility that manages foreground and background tasks. Produce one landscape image containing exactly two equally sized polished app icons, left labelled only A, right labelled only B, on a quiet warm off-white background. Both icons use the Apple macOS rounded-square silhouette, front-facing view, generous optical margins and convincing restrained layered material depth, soft studio highlights and subtle contact shadows; sleek native Apple productivity utility quality, readable at small sizes. Concept A: two offset broad smooth leaf-shaped task planes, a translucent turquoise rear layer and a luminous mint-green foreground layer, overlapping like two windows with a visible thin shadow gap, a compact abstract leaf/flow silhouette that communicates lightweight background work. Use a deep teal rounded-square base. Concept B: an entirely different geometric concept, two offset floating rounded rectangular window/task cards, one calm frosted blue rear card and a pearly ivory foreground card with a simple cobalt cutout/slot suggesting a switch between layers, a clear sculptural layered silhouette with no miniature UI details. Use a rich indigo-to-blue rounded-square base. Equal scale and lighting across A and B. The foreground/background layering must be obvious yet refined, with a shallow glass/ceramic material finish, not a busy illustration. Two concepts should have distinct recognizable shapes, not merely different colors. No other text, no Apple logo, no leaf motif in B, no sparkle, no extra symbols or device mockups. This is a preview comparison, not final icon source assets.
