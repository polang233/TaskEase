# TaskEase 需求

## 产品与平台

TaskEase，中文显示名为轻程，是 Apple Silicon Mac 上的原生菜单栏应用。目标系统为 macOS 14 及以上，使用 Xcode 27、Swift 6、SwiftUI、AppKit 和 Observation。

用户从菜单栏查看占用，为指定应用配置后台限制。后台指失去系统前台焦点或应用隐藏。仅窗口最小化而仍保留前台焦点不视为后台。离开前台后等待指定时间，再执行规则；回到前台恢复。

## 规则流程

1. 从“运行中的应用”中选择应用。
2. 打开“限制后台资源”，设置等待时间和 CPU 使用上限。
3. 打开顶部“启用后台限制”总开关。
4. 应用进入后台，等待结束后执行规则。
5. 切回应用，确认限制解除。

默认行为为“保持原样”。无有效规则时总开关关闭并置灰，点击后提示用户先设置应用规则。关闭总开关暂停执行并保留配置。已保存规则列表包含正在运行和未运行的应用；关闭某条规则保留其配置，移除规则删除该记录。

现有 rules.v1 配置继续按 bundle identifier 匹配。模式的持久化原始值保持稳定，显示名称独立调整。

## 指标

应用 CPU 使用率由累计 CPU 时间差计算，单核满载为 100%。同一应用的自有辅助进程合并显示。物理内存采用 footprint；磁盘读写和中断唤醒采用累计计数差分。

整机 CPU 来自 host 计数，以全部核心的总能力计算。GPU 是设备驱动利用率估计值，不归属某个应用。热状态提供正常、轻度升温、较高、严重四级状态。无法读取的指标显示不可用。

## 网络监控与配置

应用列表和详情提供接收、发送速度，进程信息中显示各个成员的速度。设置可关闭网络显示。数据来源为系统进程计数，第一帧及失效基线显示不可用。网络读取跟随数据面板启停。

网络规则独立保存，包含联网模式、作用时间、等待时间与上下行上限。已配置列表包含 CPU 与网络规则。当前构建支持监控与配置，执行状态为待启用网络扩展；签名与系统批准完成后再验证实际阻断和限速。详细设计见 [网络文档](Networking.md)。

## 控制规则

| 行为 | 执行方式 |
| --- | --- |
| 保持原样 | 观察占用，解除 TaskEase 施加的状态 |
| 限制 CPU 使用 | 应用自有进程共享平均 CPU 上限，超额时暂停并在额度恢复后继续 |
| 仅降低后台优先级 | 在高级选项中启用 Darwin 背景调度，前台解除本工具的请求，没有固定 CPU 上限 |

CPU 上限范围为单核的 5% 至 200%，默认 20%。后台等待范围为 0 至 300 秒，默认 3 秒。在应用已经位于后台时开启总开关，会重新开始等待时间。

限制作用于整个受控进程，可能影响声音、网络心跳和任务完成时间。精确 FPS 上限、独立 GPU 百分比配额、网络限速和传感器摄氏度读数需要单独验证。

## 应用筛选与权限

默认隐藏 Apple 系统应用，用户可在列表或设置中开启显示。自有辅助进程并入所属应用；独立系统服务和其他用户进程不加入应用控制组。

控制前验证当前用户、PID、启动时间、可执行路径和所属应用。TaskEase 自身、Apple 系统应用、共享系统服务以及已经被外部暂停的进程不接管。不解除已有的外部后台调度状态。

## 设置与窗口

当前用户按单实例运行。重复启动恢复已有管理窗口。菜单栏资源采用 18 点逻辑尺寸及 Retina 图片。管理、设置、帮助、关于和许可证窗口复用已有实例；有打开或最小化的应用窗口时保留 Dock 入口，关闭全部窗口后继续菜单栏运行。

项目采用 GPL-3.0-only。源码与应用包均包含完整许可证，关于信息提供版权、许可和无担保说明，以及许可证查看入口。

显示设置提供跟随系统、浅色、深色，以及 1、2、5、10 秒数据刷新间隔。刷新间隔只影响可见数据面板。管理窗口默认仅在前台刷新，可在设置中关闭该选项。切回前台立即更新，菜单栏面板打开时刷新。控制心跳与等待期限独立调度。

## 数据管理

设置提供“清除数据并退出…”入口。用户确认后恢复受控进程、停止采样、删除本应用配置和本地数据，再退出应用。清理范围限定为本应用偏好域与明确归属的目录。失败向用户报告并允许重试。

## 使用统计

设置提供默认关闭的匿名使用统计开关。开启后通过 PostHog Capture API 上报随机安装标识、应用版本、macOS 版本与系统地区，关闭用户资料与 IP 地区补充。当地中午安排一次上报；中午后启动或唤醒时补发当天记录。退出、睡眠和关闭开关时停止任务，失败重试有间隔与每日次数上限。统计与应用监控、资源控制相互独立。详细字段与维护流程见 [PostHog 文档](PostHog.md)。

## 性能目标

采样在独立 actor 上执行。完全遮挡、最小化或关闭数据窗口时停止显示采样；后台规则仍按需检查。没有可见数据面板和需要执行的规则时，不保留周期采样定时器，也不启动控制进程。

macOS 26 起采用类型化工作区通知，macOS 27 起采用类型化窗口可见性消息。较早系统使用公开通知执行相同流程。性能目标需用 CPU、物理内存和唤醒次数验证；实际续航与温度变化按应用另行对比。

## 验收条件

- 主开关在无有效规则时置灰；删除最后一条有效规则后关闭。
- 运行列表默认隐藏系统应用，显示开关不赋予系统进程控制权限。
- 已配置规则在应用退出后保留，支持离线编辑与移除。
- 前台切换、隐藏、等待、全局暂停和正常退出保持控制状态正确。
- 慢速显示刷新不推迟控制心跳或后台等待期限。
- 控制器失联、退出、强制结束以及重启后的恢复经过测试。
- 设置、帮助、关于、许可证窗口及 Dock 入口生命周期经过交互验证。
- 自动测试使用独立数据与自建负载进程。
