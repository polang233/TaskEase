# 使用轻程管理后台应用

## 启动应用

在项目根目录执行以下命令生成本机应用包：

```sh
sh Scripts/build-app.sh
```

双击 `build/TaskEase.app`。启动后显示管理窗口和菜单栏图标。关闭全部窗口后，轻程继续在菜单栏运行；从菜单栏、Dock 或重复启动可恢复已有窗口。

## 设置后台限制

1. 在“运行中的应用”中选择应用。
2. 打开右侧“限制后台资源”。
3. 拖动“生效时机”，可选 1 秒至 5 分钟的预设档位；拖到最左侧为“始终限制”。
4. 调整“CPU 使用上限”。
5. 打开顶部“启用后台限制”。

离开前台或隐藏应用后开始计时；等待结束后执行规则。切回应用后恢复正常运行。在应用已经位于后台时打开总开关，会重新开始等待时间。“始终限制”在前台使用时也执行，操作可能不流畅。

没有有效规则时，总开关置灰，点击它可查看配置提示。所有应用默认保持原样。

## 理解 CPU 上限

CPU 100% 约等于一个核心满载。一个应用的主进程和自有辅助进程共享上限，例如 20% 表示这些进程平均使用一个核心的五分之一。短时间内可能超过该数值。

CPU 限制会短暂暂停整个应用进程，可能影响后台声音和连接心跳。调整后观察应用是否还能完成需要的后台工作。

“限制方式”可选三种：

- 限制 CPU：按上限短暂暂停，平均占用不超过设定值。
- 降低优先级：让前台任务优先获得资源，没有固定上限，效果取决于系统竞争。
- 暂停应用：生效期间应用完全停止，不占用 CPU；后台播放、下载和消息通知都会中断，回到前台后恢复。暂停应用不能设为“始终限制”。

## 修改已保存的规则

切换到“已配置规则”。应用退出后仍保留规则，支持修改等待时间和 CPU 上限；下次运行时按保存的配置执行。

关闭某个应用的“限制后台资源”会保留参数，让它保持原样。点击“移除规则”删除记录。删除最后一条有效规则后，总开关自动关闭。

关闭顶部总开关暂停全部规则并保留配置。退出轻程会解除它施加的控制。

## 调整显示

点击右上角设置按钮或按 Command-逗号打开设置。

- 语言可选跟随系统、English、简体中文或繁體中文，重新开启轻程后生效。翻译说明见 [多语言与翻译](Localization.md)。
- 外观可选跟随系统、浅色或深色。
- 概览样式可选数字、圆环或进度条。
- 应用 CPU 口径可选单核（100% 为一个核心满载，与活动监视器一致）或整机（占全部核心的比例）。CPU 上限始终按单核设置。
- 显示刷新间隔可选 1、2、5、10 秒。
- “管理窗口仅在前台刷新”默认开启。切到其他应用后停止管理窗口数据刷新，切回立即更新；打开菜单栏面板时更新数据。
- 系统应用默认隐藏，可从列表或设置中开启显示。
- 点击“管理后台规则”打开已配置列表。

刷新间隔只影响可见面板的数据更新。后台规则的等待期限和恢复继续按规则执行。管理窗口的数据刷新暂停时，系统概览显示雪花和“已暂停刷新”，数值保留为上次采样结果；切回前台后提示消失。

## 查看网络速度与配置网络规则

网络实验默认关闭。在“设置 → 实验功能”开启“网络功能（测试）”后，列表显示接收与发送速度，详情中的“网络收发”和“应用与进程信息”提供合计及成员数据。第一帧需要建立计数基线，缺失时显示不可用。数据只包含能够归属的应用自有进程，使用共享代理或系统代发时可能不完整。

在“网络规则”选择联网方式、作用时间、后台等待和上下行上限。配置保存在“已配置规则”，应用未运行时也能编辑。当前版本提示暂缺开发者账号签名、阻断和限速尚未实现，测试配置供后续网络控制使用。顶部开关继续控制 CPU 规则。

“移除网络规则”保留 CPU 配置，应用标题的移除按钮删除该应用全部规则。设计与权限要求见 [网络文档](Networking.md)。

## 使用统计

“关于轻程 → 使用统计 → 匿名使用统计”对新安装默认开启，也可以关闭。启用状态下在启动及运行期间低频向 PostHog 发送版本、系统地区、语言、时区和本应用的功能配置概况，用随机安装标识去重。通常每 6 小时最多一次，跨日时统计当天活跃；退出、睡眠或离线时可能延迟，关闭开关停止后续发送。完整字段、调度和数据清理范围见 [PostHog 文档](PostHog.md)。

## 更新

每次启动轻程，约 3 秒后查询一次 GitHub 最新发布；之后不会定时检查。有新版本时弹出“软件更新”窗口，显示更新内容，管理窗口顶部和菜单栏面板也会出现“新版本”入口。

- 立即更新：下载安装镜像，用发布页提供的 SHA-256 校验，核对应用标识、版本与签名后，退出轻程并替换为新版本，完成后自动重新打开。退出时会先解除轻程施加的限制。替换失败时还原旧版本。
- 稍后：关闭窗口，本次运行中仍可从“新版本”入口进入。
- 跳过此版本：之后启动不再为这个版本弹窗，入口仍会显示。

轻程放在 DMG 里直接运行、或位于不可写的位置时无法原地替换，窗口会改为提供下载链接，按“开始使用”中的步骤手动安装。

## 清除数据并退出

打开设置，点击“清除数据并退出…”，确认后删除后台规则、显示偏好和本地应用数据，并恢复受控进程。轻程随即退出；之后可在访达中将应用移到废纸篓。取消确认会保留配置。数据位置见 [数据管理说明](DataAndPrivacy.md)。

## 查看指标

应用 CPU 使用单核口径，内存显示物理 footprint 合计，磁盘活动和中断唤醒按每秒显示。整机 CPU 使用全部核心的总能力口径；GPU 是整机驱动估计值。热状态表示发热对系统运行的影响程度。

系统概览保持单行，内存显示占用百分比，网速在最右侧上下两行显示上传（橙色箭头）和下载（蓝色箭头）。指针移到 CPU、GPU、内存或温度上即打开卡片，移开后关闭，在相邻指标间移动时卡片会滑到新位置；点击指标可把卡片固定住，再次点击、点到别处、按 Esc 或切换窗口时解除，点击其他指标则固定到该指标；卡片中有芯片型号、核心数、已用与压缩内存等信息。颜色从绿到红表示占用由低到高。温度为芯片传感器参考值，读取失败时显示热状态。详细口径见 [系统指标](SystemMetrics.md)。

应用列表和菜单栏面板可按 CPU、内存、GPU、磁盘、网络（开启网络显示时）或名称排序，右侧数值和下方说明跟随排序依据；“显示系统应用”也在同一个菜单里。每行背景从左向右填充表示占用，长度与数值同一口径，颜色从绿渐变到对应档位：CPU 按当前口径（单核口径以一个核心满载为满格），内存为占物理内存的比例，GPU 为执行时间占比；磁盘和网络没有固定上限，取运行中应用合计里的占比，合计很小时按 1 MB/s 和 100 KB/s 计算，避免零散读写铺满整行。

系统应用只用于观察。共享服务、其他用户进程以及不属于应用自有进程的数据不加入控制组。

从菜单栏的应用菜单打开“关于轻程”，从帮助菜单打开“轻程帮助”。设置窗口也提供这两个入口。

在“关于轻程”中点击“许可证”查看完整 GNU GPLv3 文本。项目采用 GPL-3.0-only，许可证也随应用包提供。

“问题反馈”打开 GitHub Issues，开源说明文字打开项目仓库。“使用统计”显示近 30 天活跃设备估计、每日趋势和主要地区，并提供匿名上报开关。“检查更新”可随时手动查询。
