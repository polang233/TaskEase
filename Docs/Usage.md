# 使用轻程管理后台应用

## 启动应用

在项目根目录执行以下命令生成本机应用包：

```sh
sh Scripts/build-app.sh
```

双击 `build/TaskEase.app`。启动后显示管理窗口和菜单栏图标。关闭全部窗口后，轻程继续在菜单栏运行；从菜单栏、Dock 或重复启动可恢复已有窗口。

## 设置后台限制

1. 在“运行中的应用”中选择应用。
2. 打开右侧“限制后台资源”。
3. 设置“离开前台多少秒后生效”，范围为 0 至 300 秒。
4. 调整“CPU 使用上限”。
5. 打开顶部“启用后台限制”。

离开前台或隐藏应用后开始计时；等待结束后执行规则。切回应用后恢复正常运行。在应用已经位于后台时打开总开关，会重新开始等待时间。

没有有效规则时，总开关置灰并显示配置提示。所有应用默认保持原样。

## 理解 CPU 上限

CPU 100% 约等于一个核心满载。一个应用的主进程和自有辅助进程共享上限，例如 20% 表示这些进程平均使用一个核心的五分之一。短时间内可能超过该数值。

CPU 限制会短暂暂停整个应用进程，可能影响后台声音和连接心跳。调整后观察应用是否还能完成需要的后台工作。

在“高级选项”中打开“仅降低后台优先级”，可让前台任务优先获得资源。该模式没有固定 CPU 上限，效果取决于系统竞争和应用工作负载。

## 修改已保存的规则

切换到“已配置规则”。应用退出后仍保留规则，支持修改等待时间和 CPU 上限；下次运行时按保存的配置执行。

关闭某个应用的“限制后台资源”会保留参数，让它保持原样。点击“移除规则”删除记录。删除最后一条有效规则后，总开关自动关闭。

关闭顶部总开关暂停全部规则并保留配置。退出轻程会解除它施加的控制。

## 调整显示

点击右上角设置按钮或按 Command-逗号打开设置。

- 外观可选跟随系统、浅色或深色。
- 显示刷新间隔可选 1、2、5、10 秒。
- 系统应用默认隐藏，可从列表或设置中开启显示。
- 点击“管理后台规则”打开已配置列表。

刷新间隔只影响可见面板的数据更新。后台规则的等待期限和恢复继续按规则执行。

## 查看指标

应用 CPU 使用单核口径，内存显示物理 footprint 合计，磁盘活动和中断唤醒按每秒显示。整机 CPU 使用全部核心的总能力口径；GPU 是整机驱动估计值。热状态表示发热对系统运行的影响程度。

系统应用只用于观察。共享服务、其他用户进程以及不属于应用自有进程的数据不加入控制组。

从菜单栏的应用菜单打开“关于轻程”，从帮助菜单打开“轻程帮助”。设置窗口也提供这两个入口。
