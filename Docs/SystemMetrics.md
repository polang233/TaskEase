# 系统概览

管理窗口使用一行概览，窄菜单面板自动切换为两行。内存和网速使用上下两层数值，暂停刷新时保留静态雪花提示。颜色只辅助扫读，不改变后台控制规则。

## 数据口径

| 指标 | 口径 |
| --- | --- |
| 顶部 CPU | Mach 的整机 CPU 时间差分，占全部核心总时间的百分比，满载为 100% |
| 应用 CPU | 主进程与自有辅助进程的累计 CPU 时间，一个核心满载约为 100%，多核心可超过 100% |
| GPU | AGX 驱动提供的整机利用率估计；缺失时显示 — |
| 内存 | 已用物理内存 / 硬件总容量，排除可回收的文件缓存与可清除页 |
| 压缩 | 压缩器实际占用的物理内存，已包含在已用内存内，不再次相加 |
| 下载、上传 | 活动物理 en* 接口的 64 位字节计数差分；单位 MB/s，1 MB 为 1,000,000 字节 |
| 温度 | 可读芯片温度传感器中的最高值，显示一位小数 |
| 热状态 | 系统的正常、轻度升温、较高、严重四档运行状态 |

内存使用 `host_statistics64` 的匿名页、不可分页的 wired 页与压缩器页计算，减去可清除页，并按实际页大小换算。该数值是系统快照，不包含进程内存合计中可能重复计算的共享页。应用列表仍显示各进程的 physical footprint 合计。

全局网络直接读取 BSD `NET_RT_IFLIST2`，为每张网卡保留独立基线。新增接口、计数回退、时间回退和超过二十秒的暂停会重新起算，第一帧速度使用占位符。VPN、回环与桥接虚拟接口不重复累加；数值包含局域网和物理网卡的协议流量，不等于某个应用的下载速度。全局概览独立于应用级网络实验开关。

## 温度读取

当前使用非公开 AppleSMC 的只读消息接口，仅执行读取元数据与读取数值两类操作。支持已识别的 `flt ` 和 `sp78` 编码，忽略不存在、无效或超出范围的值，读取完成立即关闭连接。没有风扇设置、SMC 写操作或管理员服务。

在 M5 MacBook Air、macOS 27.0.1 上验证到真实摄氏度读数。传感器键与核心位置没有统一公开映射，因此显示“芯片最高”，不将它标为某个具体核心。其他机型和后续系统可能限制该接口；读取失败时继续显示公开的系统热状态。

显示分辨率为 0.1°C，不能据此承诺 0.1°C 的测量准确度。Apple 未公开这些传感器的误差范围。系统热状态也不能转换成摄氏度。

## 配色与开销

占用比例在 40%、60%、80% 切换为黄、橙、红，较低为绿。应用 CPU 的颜色按可用核心数归一，显示数字继续使用单核口径。内存颜色表示物理占用比例，不代表系统内存压力。

温度配色在 50°C、70°C、85°C 切换；同时考虑系统热状态，选用两者中较高的提示等级。这些是界面配色参考值，不是 Apple 的过热判定阈值。

GPU 与温度共用最快四秒的硬件缓存；内存和全局网络跟随显示刷新间隔。全部读取在采样 actor 中执行。窗口不可见或按前台刷新选项暂停时，系统指标停止采样，后台规则的控制采样保持原有独立周期。

本机连续二十次内存、网卡与温度组合读取平均墙钟耗时为 8.86ms。该测量不包含现有进程扫描、界面绘制和网络请求，不代表应用整体 CPU 占用。实际核验见 [系统概览记录](../Artifacts/system-overview.json)。
