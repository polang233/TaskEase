# 协作网络中继实验

Python 3.9+ 标准库模块，独立于 TaskEase 应用构建。中继只监听 127.0.0.1 的临时端口，目标固定为自建本机服务；实验不修改代理设置、PF 规则或其他应用连接。

```sh
cd Experiments/NetworkRelay
python3 -m unittest -v
```

测试验证允许传输、连接上游前阻断、上下行限速及多连接共享额度。缓冲块上限为 4 KiB，采用背压，初始突发最多一个块。

应用主动把 TCP 流量交给代理时，可以实现阻断和速度限制。通用桌面应用不会自动把全部流量交给这份中继；透明捕获、应用身份归属、UDP/QUIC 和已建立连接的接管仍需系统流量接口。本模块验证代理路径，未接入产品的网络规则执行。
